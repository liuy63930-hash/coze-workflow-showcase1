# AI Workflow Automation System

An AI-powered workflow automation project built with Coze.

## Features

- URL content extraction
- Structured data processing
- Image parsing
- Automated Feishu table integration
- Workflow-based automation

## Workflow Overview

This workflow allows users to input a URL, automatically extracts content through plugins, processes structured data, and stores the results into Feishu tables.

## Tech Stack

- Coze Workflow
- JSON Workflow Configuration
- Feishu Integration
- AI Content Processing
